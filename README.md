# Mosquée Anas Ibn Malik — Affichage des horaires

Site autonome, prévu pour une télévision, un ordinateur et un téléphone.

## Modifier les informations

Ouvrir `config.js` dans GitHub puis cliquer sur le crayon. Modifier uniquement les heures, annonces et textes du fichier. Les heures actuelles sont des exemples.

## Publier gratuitement sur GitHub Pages

1. Créer un nouveau dépôt GitHub public nommé `mosquee-anas-ibn-malik`.
2. Envoyer tous les fichiers de ce dossier dans ce dépôt.
3. Dans **Settings → Pages**, sélectionner **Deploy from a branch**, puis choisir la branche `main` et le dossier `/ (root)`.
4. GitHub affichera l'adresse publique après quelques minutes.

La page ne contient aucune partie IQRA974.
